# Allora — Progress

Booking and planning platform where customers create events, book vendors, and see AI-powered gaps in their plan, while vendors manage bookings in a portal.

## Features (in build order)

| # | Feature | Status | Branch | Notes |
|---|---------|--------|--------|-------|
| 1 | Setup and auth | done | `feature/auth-backend`, `feature/auth-frontend`, `feature/auth-connect` | Supabase Auth, `profiles` with role, route protection, RLS |
| 2 | Events, vendor browsing and booking | done | `feature/events-booking-backend`, `feature/events-booking-frontend`, `feature/events-booking-connect` | Create event, browse vendors by category, book, view plan with status |
| 3 | Vendor portal | done | `feature/vendor-portal-backend`, `feature/vendor-portal-frontend`, `feature/vendor-portal-connect` | Incoming bookings, accept or decline, status shows on customer plan |
| 4 | Smart matching and "What's missing" cards | done | `feature/matching-backend`, `feature/matching-frontend`, `feature/matching-connect` | Deterministic budget-share ranking, AI writes reason text only |
| 5 | Planning chatbot | done | `feature/chatbot-backend`, `feature/chatbot-frontend`, `feature/chatbot-connect` | Knows event and bookings, ordered list of what to book first and last |
| 6 | Vendor upgrades | not started | _tbd_ | Vendor profile, change decision, customer name and budget; needs features 3 and 4 merged |
| 7 | Polish and deploy to Vercel | not started | _tbd_ | Final polish, production deploy |
